# Lysozyme in Water Molecular Dynamics Simulation

## Overview

This project demonstrates a complete molecular dynamics (MD) simulation workflow of lysozyme in water using GROMACS.

The simulation includes system preparation, solvation, ion addition, energy minimization, equilibration, production MD, and basic trajectory analysis.

---

## Protein

- Protein: Lysozyme
- PDB ID: 1AKI

---

## Software

- GROMACS
- Ubuntu (WSL2)

---

## Workflow

1. Protein preparation
2. Define simulation box
3. Solvate the system
4. Add ions
5. Energy minimization
6. NVT equilibration
7. NPT equilibration
8. Production MD simulation
9. Trajectory analysis
